Conditional wildcards

Use @if{bikini=__bikini_or_die__} to expand __bikini_or_die__ only when the fully expanded prompt contains a tag with the text bikini, such as white bikini. Conditional wildcards run after all regular Dynamic Prompts syntax. Put each conditional expression between commas like a normal prompt tag.

Separate ordered fallback branches with |: @if{bikini=__bikini_or_die__, torogao | swimsuit=torogao, see-through}. Commas separate tags in a branch result, which may contain literal tags, one wildcard, or multiple wildcards. The first matching branch is used; if none match, nothing is added.

Wildcard-only Anima sections

Content wrapped in @anima{...} inside a wildcard-file line is treated as Anima-only content and removed. For example, character, @anima{Anima tags}, Illustrious tags becomes character, Illustrious tags when selected through __wildcard__. Nested braces are supported. Existing square-bracket prompt syntax is not changed.

Selective combinatorial generation

With Combinatorial generation enabled, only content wrapped in @combination{...} is enumerated. For example, @combination{__blueaka_swimsuit__}, __pose__ generates one prompt for every line in blueaka_swimsuit.txt, while __pose__ is chosen randomly again for every generated prompt. Wrapped wildcard rows follow their original text-file order instead of being alphabetically sorted.

Multiple @combination{...} blocks form a Cartesian product with each other. Unwrapped wildcards and variants remain random. A Max generations value of 0 enumerates all marked combinations. Combinatorial batches repeats the marked set, and rerolls every unwrapped wildcard and variant for each repeated batch. With Seed set to -1 and Fixed seed disabled, every generated image also receives an independent random seed instead of a sequentially incremented seed. Repeated results for the same marked combination are placed next to each other.

Combinations

Choose a number of terms from a list, in this case we choose two artists: {2$$$$artist1|artist2|artist3}
If $$$$ is not provided, then 1$$$$ is assumed.

If the chosen number of terms is greater than the available terms, then some terms will be duplicated, otherwise chosen terms will be unique. This is useful in the case of wildcards, e.g. {2$$$$__artist__} is equivalent to {2$$$$__artist__|__artist__}

A range can be provided: {1-3$$$$artist1|artist2|artist3}
In this case, a random number of artists between 1 and 3 is chosen.

Options can be given weights: {2::artist1|artist2}
In this case, artist1 will be chosen twice as often as artist2.

Wildcards can be used and the joiner can also be specified: {{1-$$$$and$$$$__adjective__}}
Here, a random number between 1 and 3 words from adjective.txt will be chosen and joined together with the word 'and' instead of the default comma.

Wildcards

Find and manage wildcards in the Wildcards Manager tab. Wildcard rows keep their original text-file order and are not alphabetically sorted. This applies to both ordinary random wildcards and selective combinations.

You can add more wildcards by creating a text file with one term per line and name is mywildcards.txt. Place it in ${WILDCARD_DIR}. __<folder>/mywildcards__ will then become available.

Variables
